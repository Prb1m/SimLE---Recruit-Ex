# Zadanie Rekrutacyjne

Klasa "czarnej skrzynki" na zadanie rekrutacyjne koła naukowego SimLE

##  Instalacja

```bash
git clone https://github.com/username/repository.git
cd repository
```

## Uruchomienie

```bash
g++ -std=c++17 main.cpp -o program
./program
```

## Funkcje

Pomijając funkcje w programie przykładowym dodano

- printBinary - Funkcja pomocnicza do wypisywania bitowego liczby
- printCurrentFrame - Funkcja pomocnicza do wypisywania ramki rakiety
- printHistory - Funkcja do testowania histori
- printAltitude - Funkcja do testowania mierzenia wysokości

## Pliki

- TelemetryBlackBox.cpp - plik klasy czarnej skrzynki
- main.cpp - plik zawierający testy oraz wywołanie testów w pętli
